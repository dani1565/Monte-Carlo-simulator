# ADR 0005 — ממוצע זנב חיובי

- מצב: Accepted
- תאריך: 2026-08-26
- מימוש: https://github.com/dani1565/Monte-Carlo-simulator/pull/7
- בדיקות: `src/simulation/statistics.test.ts`, `src/simulation/engine.test.ts`, `src/state/parameterStorage.test.ts`, `e2e/simulator.spec.ts`

## הקשר

CVaR מציג את ממוצע תרחישי הקצה הגרועים. נדרש מדד מקביל לצד התוצאות הטובות.

## החלטה

המשתמש בוחר אחוז חיובי עצמאי בין 1% ל־25%. המדד הוא ממוצע `max(1, ceil(N × p))` הערכים הסופיים הגבוהים ביותר.

## חלופות שנדחו

- להשתמש באותו אחוז של CVaR בלי קלט נפרד.
- להציג רק אחוזון עליון.
- לתאר את המדד כתשואה צפויה.

## השלכות

הפרמטר נשמר ב־URL וב־localStorage. קישורים ישנים שאינם כוללים אותו מקבלים ברירת מחדל 5%.

## אישור עתידי

שינוי ההגדרה, העיגול או טווח האחוזים דורש אישור בעלים ובדיקות מתמטיות ותאימות.
