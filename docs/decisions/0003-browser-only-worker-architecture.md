# ADR 0003 — חישוב בדפדפן וב־Web Worker

- מצב: Accepted
- תאריך: 2026-08-12
- מימוש: https://github.com/dani1565/Monte-Carlo-simulator/pull/2
- בדיקות: `src/simulation/engine.test.ts`, `e2e/simulator.spec.ts`

## הקשר

הסימולציה יכולה להיות כבדה, אך הקלטים הפיננסיים אינם צריכים שרת או חשבון משתמש.

## החלטה

המנוע רץ ב־Web Worker בדפדפן. האפליקציה סטטית ונפרסת ב־GitHub Pages. ה־UI מקבל progress/result בהודעות ואינו נחסם בזמן החישוב.

## חלופות שנדחו

- API או job server להרצות.
- חישוב ארוך ב־main thread.
- אחסון תרחישים בענן.

## השלכות

יש מגבלות משאבי דפדפן, אך נשמרים פרטיות, פשטות פריסה ועלות אפסית. יש לבדוק ביצועים בדפדפן אמיתי.

## אישור עתידי

שרת, מסד נתונים, חשבונות או אחסון ענן דורשים אישור בעלים ותכנון פרטיות/עלות.
