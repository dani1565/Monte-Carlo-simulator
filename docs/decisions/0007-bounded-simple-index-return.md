# ADR 0007 — רצפת ‎-100% לתשואת מדד פשוטה

- מצב: Accepted
- תאריך: 2026-08-30
- Issue: https://github.com/dani1565/Monte-Carlo-simulator/issues/22
- מימוש: https://github.com/dani1565/Monte-Carlo-simulator/pull/23
- בדיקות: `src/simulation/engine.test.ts`, `e2e/simulator.spec.ts`

## הקשר

המודל יצר תשואה יומית פשוטה ישירות מהתפלגות Student-t מנורמלת. להתפלגות זו תמיכה על כל הישר הממשי, ולכן היא יכולה לייצר תשואת מדד נמוכה מ־‎-100% — תוצאה שאינה אפשרית עבור תשואה פשוטה משום ששווי המדד אינו יכול להיות שלילי.

רצפת האפס של ADR 0001 הוחלה רק לאחר הכפלת תשואת המדד במינוף. כך נשמר תיק לא שלילי, אך תרחישים עם מינוף קטן מ־1 עדיין הושפעו מתשואת מדד בלתי אפשרית ואף יכלו להימחק בעקבותיה.

## החלטה

תחילה נוצרת תשואה גולמית בדיוק באותה דרך ובאותו רצף אקראי:

```text
r_raw = μ / D + σ / √D × T(df) × √((df - 2) / df)
```

לפני החלת המינוף היא נחסמת כרצפה מתמטית של תשואה פשוטה:

```text
r = max(-1, r_raw)
```

עדכון התיק נשאר ללא שינוי:

```text
V(t+1) = V(t) × max(0, 1 + L × r)
```

אין פרמטר חדש, ואין שינוי בערכי ה־presets, בכיול `df`, בסכמת URL/localStorage או בהגדרת מדדי התוצאה.

## חלופות שנדחו

- דגימה חוזרת מ־Student-t עד לקבלת ערך חוקי — נמנעת מסה ב־‎-100%, אך צורכת מספר הגרלות משתנה ושוברת את רצף ה־seed לאחר הדחייה הראשונה.
- טרנספורמציה רציפה של כל הזנב השלילי — נמנעת מסה נקודתית, אך משנה כל תשואה שלילית ואת משמעות פרמטרי התשואה והתנודתיות.
- מעבר לתשואות לוג או להתפלגות אחרת — שינוי מודל וכיול רחב שאינו נחוץ לתיקון האילוץ המתמטי.
- שמירת ההתנהגות הקודמת — משאירה תשואות פשוטות בלתי אפשריות ופוגעת במיוחד בפרשנות של מינוף קטן מ־1.

## השלכות

- תשואת המדד שנכנסת למודל המינוף לעולם אינה נמוכה מ־‎-100%.
- ספי המחיקה הטבעיים של מינוף 1× ומעלה אינם משתנים. עבור אותו רצף גולמי, כל הערכים הפיננסיים ברמות `L ≥ 1` נשארים זהים גם כאשר `r_raw < -1`, משום ששתי הגרסאות מאפסות את התיק.
- עבור `0 < L < 1`, אירוע של אובדן מדד מלא משאיר את החלק שאינו חשוף; תוצאות ישנות עשויות להשתנות רק אם הרצף שלהן כלל `r_raw < -1`.
- אותו seed צורך בדיוק אותן הגרלות ומפיק אותו רצף Student-t גולמי. אין הבטחה לתוצאה מספרית ישנה זהה בתרחיש מינוף קטן מ־1 שנפגע מהתנהגות העבר.
- החסימה יוצרת מסה נקודתית ב־‎-100%. בתרחישי זנב קיצוניים היא עשויה להעלות מעט את הממוצע ולהפחית מעט את התנודתיות הממומשים ביחס להתפלגות הגולמית.
