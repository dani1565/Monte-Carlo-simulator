# ADR 0006 — analytics מצרפי וממוקד פרטיות

- מצב: Accepted
- תאריך: 2026-08-13
- מימוש: https://github.com/dani1565/Monte-Carlo-simulator/pull/5
- בדיקות: `e2e/simulator.spec.ts`

## הקשר

נדרש מידע מצרפי על שימוש וביצועים בלי להפוך את האפליקציה למערכת פרופילים או לאסוף קלטים פיננסיים.

## החלטה

Cloudflare Web Analytics מאושר כ־beacon ציבורי למדידה מצרפית, ללא עוגיות וללא פרופיל אישי. קוד האפליקציה אינו שולח פרמטרי סימולציה, קלטים פיננסיים, custom events, חשבונות או מזהי משתמש.

## חלופות שנדחו

- analytics מבוסס cookies.
- custom event tracking של פרמטרים.
- מערכת analytics עצמית או חשבונות.

## השלכות

הגילוי מופיע בממשק ונבדק בדפדפן. ה־site token ציבורי מטבעו ואינו secret.

## אישור עתידי

כל ספק נוסף, cookie, event, מזהה, retention או איסוף קלט דורש אישור בעלים ועדכון פרטיות/בדיקות.
