# מסלול — סימולטור מונטה קרלו ממונף

יישום אינטראקטיבי לניתוח אלפי עתידים אפשריים של השקעה במדד S&P 500 באמצעות מינוף יומי. הכלי מדגיש את הפער בין התוצאה הממוצעת לתוצאה החציונית, את שיעור החורבן ואת ההפסד הצפוי בתרחישים הגרועים ביותר.

> **הבהרה:** זהו כלי מחקרי וחינוכי בלבד. התוצאות אינן תחזית ואינן מהוות ייעוץ השקעות.

## יכולות עיקריות

- השוואה ישירה בין רמות מינוף `1×` עד `5×` על אותם מסלולי שוק.
- תשואות יומיות מהתפלגות Student-t עם עובי זנבות ניתן לשליטה.
- רצפת שווי טבעית של אפס בלבד: אין סף מלאכותי שמוחק תיק שעדיין נותר בו ערך.
- חישוב אלפי מסלולים ב־Web Worker, עם חיווי התקדמות וממשק שאינו נחסם.
- חישוב מחדש באופן אוטומטי לאחר שינוי פרמטר, עם השהיה קצרה שמונעת עומס בזמן גרירה.
- גרף מסלולים לוגריתמי עם חציון, ממוצע ורצועות אחוזונים.
- היסטוגרמת שווי סופי ומדדי חציון, ממוצע, שיעור חורבן ו־CVaR.
- תרחישי שוק מוכנים ומחולל אקראי ניתן לשחזור באמצעות seed.
- ממשק כהה, מלא בעברית ובכיוון RTL.

## המודל המתמטי

כל שנה כוללת 252 ימי מסחר. התשואה היומית של המדד מחושבת כך:

```text
r = μ / 252 + σ / √252 × T(df) × √((df - 2) / df)
```

הגורם האחרון מנרמל את שונות התפלגות Student-t. לכן הממשק מגביל את `df` לטווח 3–30, שבו קיימת שונות סופית. לכל מסלול שוק מוחלות כל רמות המינוף שנבחרו, כדי שההשוואה ביניהן לא תושפע מרצפים אקראיים שונים.

תשואת התיק הממונף בכל יום היא:

```text
V(t+1) = V(t) × max(0, 1 + L × r)
```

כאשר התשואה היומית הממונפת מוחקת את מלוא השווי, התיק מגיע לאפס ונשאר שם. ירידה מתחת לאחוז שרירותי אינה גורמת למחיקה.

## ארכיטקטורה

- `src/simulation/engine.ts` — לולאת הסימולציה והפקת התוצאות.
- `src/simulation/random.ts` — מחולל אקראי עם seed ודגימה מ־Student-t.
- `src/simulation/statistics.ts` — אחוזונים, CVaR והיסטוגרמה.
- `src/simulation/simulation.worker.ts` — הרצת החישוב מחוץ לתהליך הממשק.
- `src/components/Charts.tsx` — גרפי Canvas חסכוניים בתלויות.
- `src/App.tsx` — בקרי המשתמש, תרחישים ותצוגת המדדים.
